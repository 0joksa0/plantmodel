\section*{S1. Parameter provenance ledger}

This table is the complete machine-readable provenance ledger of the released
model, reproduced from \texttt{config/parameter\_provenance.csv}. It is the full
form of the curated physical parameter table given in the main text
(Table~2). The tier column states how each value was obtained: T1 measured, T2
derived, T3 inherited from the source model, T4 constrained by physics or
chemistry, T5 fitted, T6 unsourced. The ledger holds 124 entries: 4 measured
(T1), 55 derived (T2), 27 inherited (T3), 9 constrained (T4), 15 fitted (T5) and
14 unsourced (T6). Every key of the released configuration appears in the ledger,
as does every constant hard-coded in the model source, and every ledger value
that names a configuration key matches the value the reported runs load; these
properties are checked by script rather than by reading.
